PORTFOLIO DETAILS

Rail Derailment Emergency Evacuation Planning

ArcGIS Pro • ModelBuilder • Network Analyst • Location-Allocation

Project Overview

This project developed a GIS-based emergency evacuation model for a simulated rail derailment scenario in Windsor, Ontario. The analysis focused on identifying affected populations, evaluating suitable emergency shelters, allocating residents to facilities, and planning evacuation routes.

ArcGIS Pro, ModelBuilder, Network Analyst, and location-allocation tools were used to organize the workflow, analyze travel conditions, and support emergency-response decision-making. Restricted railway corridors and accident zones were considered so that proposed routes could avoid hazardous areas.

Purpose:

Project Objectives

  • Identify population locations inside emergency evacuation zones.
  • Evaluate schools and community facilities as potential shelters.
  • Allocate affected residents to suitable emergency facilities.
  • Prevent routes from crossing restricted accident areas.
  • Automate important analysis steps using ModelBuilder.

Methods and Tools

A transportation network dataset was configured for emergency response travel. Population locations were used as demand points, while schools and community facilities were assessed as potential shelters.

Location-allocation and routing tools were used to identify suitable evacuation destinations and travel paths. ModelBuilder helped organize and automate parts of the workflow.

Skills Demonstrated

Network dataset configuration, location-allocation analysis, emergency-response planning, ModelBuilder automation, spatial data integration, cartographic design, and public-safety GIS.

Project Outcome

The resulting analysis provided a structured emergency-response workflow for identifying affected populations, selecting suitable shelters, and evaluating evacuation routes under simulated hazard conditions.
