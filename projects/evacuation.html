NETWORK ANALYSIS

Rail Derailment Emergency Evacuation Planning

ArcGIS Pro • ModelBuilder • Network Analyst • Location-Allocation

Project Overview

This project developed a GIS-based emergency evacuation model for a simulated rail derailment scenario. The analysis examined evacuation zones, shelter selection, population allocation, transportation restrictions, and emergency routing using ArcGIS Pro and Network Analyst.

Project Objectives

  • Identify populations located within emergency evacuation zones.
  • Evaluate schools and community facilities as evacuation shelters.
  • Allocate residents to suitable emergency facilities.
  • Avoid restricted railway corridors and accident zones.
  • Automate portions of the analysis using ModelBuilder.

Methods and Tools

A transportation network dataset was configured for emergency-response travel. Population locations were used as demand points, while schools and community facilities were assessed as potential shelters. Location-allocation and routing tools were used to identify suitable evacuation destinations and travel paths.

Skills Demonstrated

Network dataset configuration, location-allocation analysis, emergency-response planning, ModelBuilder automation, spatial data integration, cartographic design, and public-safety GIS.
