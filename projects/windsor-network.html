Emergency Response Network Analysis for Windsor

ArcGIS Pro • Network Analyst • Service Area • Closest Facility • Travel-Time Analysis

Project Overview

This project evaluated emergency-response coverage in Windsor, Ontario, using a custom road-network dataset and travel-time modelling. The analysis examined existing fire-station service areas and assessed how a proposed marine fire station could improve response coverage across the city.

Service-area analysis was used to map 0–0.5, 0.5–2.5, and 2.5–5.5-minute travel zones. Closest-facility analysis was also used to identify the most suitable fire station for responding to an incident at the CPCK rail yard.

Project Objectives

  • Create a road-network dataset for emergency-response analysis.
  • Configure travel-time and distance cost attributes.
  • Map fire-station service areas using multiple response-time cutoffs.
  • Assess the impact of a proposed marine fire station.
  • Identify the closest facility to the CPCK rail yard.

Methods and Tools

Road-segment length and speed attributes were used to calculate travel time. These values were configured as network costs within a custom emergency-response travel mode.

Service-area analysis was used to compare coverage before and after adding the proposed station. Closest-facility analysis was used to evaluate emergency routing to the rail-yard incident.

Skills Demonstrated

Network-dataset creation, travel-mode configuration, cost attributes, field calculations, service-area analysis, closest-facility routing, spatial summarization, Excel reporting, and cartographic design.

Project Outcome

The analysis demonstrated improved emergency-response coverage after adding the proposed marine station. It also identified Fire Hall #4 as the closest facility to the CPCK rail yard and provided measurable changes in the number of schools, parks, dwellings, and residents served within the target response time.
